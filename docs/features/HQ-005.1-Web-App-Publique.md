# HQ-005.1 — Web App publique en lecture seule

## Statut

À valider dans l'environnement Apps Script.

## Objectif

Fournir la première interface publique du Questionnaire santé des mineurs,
accessible par une Web App Apps Script, responsive et conforme à l'identité
visuelle de l'Association Karaté Serémange.

## Périmètre

- point d'entrée `doGet()` ;
- chargement de la campagne active ;
- refus des campagnes absentes, introuvables ou fermées ;
- chargement du questionnaire associé ;
- DTO public sans identifiants techniques ;
- parcours en deux étapes : identité puis questionnaire ;
- charte AKS avec le bleu `#2a4b9b` ;
- aucune soumission, persistance, génération PDF ou notification.

## Données d'identité affichées

- adresse mail ;
- nom et prénom du mineur ;
- date de naissance ;
- sexe ;
- nom et prénom de la personne exerçant l'autorité parentale.

## Confidentialité

HQ-005.1 n'envoie et ne stocke aucune réponse. Le bouton d'envoi reste désactivé.
Le HTML ne reçoit ni identifiant de campagne ni identifiant de questionnaire.

## Critères d'acceptation

1. La Web App s'ouvre depuis son URL de déploiement.
2. La campagne active ouverte est affichée.
3. L'étape 1 valide les champs obligatoires avant de continuer.
4. L'étape 2 affiche toutes les questions dans l'ordre.
5. Le bouton Retour revient à l'étape 1 sans perdre les valeurs saisies.
6. L'interface reste utilisable sur smartphone.
7. `AKS_runHQ0051Tests()` réussit à 5/5.
