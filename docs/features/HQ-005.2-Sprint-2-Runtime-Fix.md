# HQ-005.2 Sprint 2 — Correctif d'exécution client

## Problème

La vue injectait directement `viewModel.flow` dans une instruction JavaScript. En cas de rendu incomplet, le navigateur recevait une instruction invalide et arrêtait tout le script client.

## Correction

Le flux de navigation est désormais reconstruit depuis les éléments HTML `data-step-id` et le stepper déjà rendu. Aucune donnée JSON n'est injectée dans une instruction JavaScript.

## Effet

La validation des champs, les messages et l'activation du bouton Continuer peuvent s'initialiser normalement.
