# HQ-005.2 — Sprint 3 — Questionnaire

## Statut

Prêt pour recette.

## Objectif

Rendre l'étape Questionnaire utilisable, accessible et neutre, sans soumission ni persistance.

## Comportement

- Les questions sont chargées depuis la définition du questionnaire.
- Chaque question propose deux choix visuellement neutres : Oui et Non.
- Le choix sélectionné est indiqué par le bleu AKS et une coche.
- Toutes les questions obligatoires doivent recevoir une réponse.
- Le bouton Continuer reste désactivé tant que le questionnaire est incomplet.
- Les réponses restent uniquement dans le navigateur.
- Aucun enregistrement dans `HQ_Submissions` n'est effectué.

## Accessibilité

Les contrôles radio natifs restent présents pour le clavier et les lecteurs d'écran. L'état sélectionné ne repose pas uniquement sur la couleur : une coche est également affichée.

## Hors périmètre

- déclaration sur l'honneur ;
- soumission serveur ;
- génération PDF ;
- envoi d'e-mails.
