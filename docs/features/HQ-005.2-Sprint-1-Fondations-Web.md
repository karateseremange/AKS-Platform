# HQ-005.2 — Sprint 1 — Fondations Web

## Statut

À valider.

## Objectif

Refactoriser la Web App publique validée en HQ-005.1 sans modifier son comportement métier.

## Contenu

- shell HTML unique ;
- styles isolés ;
- JavaScript de navigation isolé ;
- pages Identité, Questions et Erreur séparées ;
- composants Marque et En-tête séparés ;
- flux de navigation décrit par le contrôleur ;
- navigation progressive sans rechargement ;
- aucune soumission ni persistance.

## Compatibilité

Le parcours reste composé de deux étapes afin de préserver HQ-005.1. Les écrans RGPD et Déclaration seront ajoutés dans les sprints fonctionnels suivants.

## Critères d’acceptation

- les tests HQ-005.1 restent verts ;
- les trois tests du Sprint 1 réussissent ;
- le parcours visuel reste identique ;
- les boutons Continuer et Retour fonctionnent ;
- aucune requête serveur n’est déclenchée par le formulaire ;
- aucune réponse n’est enregistrée.
