# HQ-005.2 — Sprint 4.1 — Moteur de décision

## Statut

À valider.

## Objectif

Déterminer le résultat réglementaire à partir des réponses transitoires :

- aucune réponse `YES` → `NO_MEDICAL_CERTIFICATE_REQUIRED` ;
- au moins une réponse `YES` → `MEDICAL_CERTIFICATE_REQUIRED`.

## Confidentialité

Le moteur ne conserve ni identifiant de question ni réponse détaillée. Le résultat retourné contient seulement :

- le résultat administratif ;
- le nombre de réponses positives ;
- la date de décision.

Le nombre de réponses positives est transitoire et ne constitue pas une donnée à persister dans `HQ_Submissions`.

## Dépendances

Le moteur dépend uniquement du domaine Questionnaire santé. Il ne dépend pas de Google Sheets, Apps Script, Gmail, Drive, HTML ou du contrôleur Web.

## Critères d’acceptation

- Les tableaux et les objets de réponses sont acceptés.
- Seules les valeurs `YES` et `NO` sont acceptées.
- Une collection absente ou vide est refusée.
- Le résultat est immuable.
- Aucun détail des réponses n’est exposé dans le résultat.
