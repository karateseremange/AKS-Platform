# HQ-005.2 — Sprint 2 — Correctif UX et validation

## Objet

Corriger les anomalies constatées lors de la recette du Sprint 2 :

- saison affichée deux fois ;
- connecteur du stepper traversant le libellé « Identité » ;
- moteur de validation client non initialisé dans certains chargements de la Web App ;
- absence de retour visible après la sortie d'un champ invalide.

## Comportement attendu

- Le nom de campagne n'est affiché qu'une seule fois.
- Le connecteur du stepper reste visuellement derrière les libellés.
- Un champ obligatoire quitté vide affiche un message sous le champ.
- Le bouton Continuer reste désactivé tant que l'identité est invalide.
- Lorsque tous les champs sont valides, le bouton devient actif.
- La validation s'initialise après `DOMContentLoaded` lorsque nécessaire.
