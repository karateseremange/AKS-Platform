# HQ-005.2 Sprint 3.1 — Correctif de cycle de vie

## Problème

La commande `AKS_upgradeHQ0052Sprint31()` appelait `AKS_start()`. Le démarrage charge le descripteur du module, mais n'exécute pas `Module.install()`. Les services du module n'étaient donc pas enregistrés dans le conteneur.

## Correction

La commande appelle désormais `AKS_install()` avant de résoudre `healthQuestionnaire.repository`. L'installation est idempotente et garantit l'enregistrement des dépendances du module.
