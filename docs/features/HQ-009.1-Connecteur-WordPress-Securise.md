# HQ-009.1 — Connecteur WordPress sécurisé

## Objectif

Établir une passerelle de production entre le site WordPress du club et le
workflow du questionnaire Apps Script, sans stockage de réponses dans WordPress.

## Contrat API

Les actions signées disponibles sont :

- `context` : modèle public de la campagne et du questionnaire ;
- `prepare` : validation éphémère des réponses et calcul de la formalité ;
- `submit` : workflow existant de soumission, PDF et notifications.

L'enveloppe utilise la version `1`, un timestamp Unix, un nonce aléatoire, la
charge JSON sous forme de chaîne et une signature HMAC-SHA256 encodée en
Base64 URL-safe.

## Confidentialité

- aucune table WordPress créée ;
- aucune réponse dans les options ou transients ;
- aucune réponse incluse dans la clé anti-rejeu Apps Script ;
- réservation atomique du nonce sous verrou pour bloquer les appels concurrents ;
- aucun secret exposé au navigateur ;
- validation de l'authenticité avant décodage de la charge métier.

## Limite volontaire

HQ-009.1 fournit la passerelle sécurisée et ses tests. Le shortcode et
l'interface utilisateur responsive sont inclus dans HQ-009.2 ; la page
`QuestionnaireMineur` reste donc en brouillon pendant cette étape.
