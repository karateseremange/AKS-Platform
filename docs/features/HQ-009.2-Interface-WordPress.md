# HQ-009.2 — Interface WordPress du questionnaire mineur

## Objectif

Afficher le parcours complet sur le domaine du club grâce au shortcode
`[aks_health_questionnaire]`, sans exposer la Web App Apps Script au navigateur.

## Fonctionnement

- chargement du contexte par la passerelle signée HQ-009.1 ;
- saisie de l'identité et de la date de naissance adaptée au mobile ;
- génération dynamique des questions depuis la campagne active ;
- préparation éphémère de la formalité ;
- déclaration sur l'honneur et soumission idempotente ;
- confirmation avec référence, formalité et rappel des courriers indésirables.

## Sécurité et confidentialité

- secret HMAC absent du navigateur ;
- nonce REST et contrôle d'origine ;
- limitation par empreinte technique de l'adresse IP et par route ;
- transient limité au compteur technique, sans identité ni réponse ;
- aucune table, option ou journal contenant les réponses ;
- réponses effacées du DOM après la confirmation.

## Intégration

Les feuilles de style sont préfixées par `.aks-hq`. Elles sont chargées avec le
script uniquement sur une page où le shortcode est rendu. La cible validée est
WordPress 7, OceanWP, Elementor et PHP 8.3.

## Validation réelle

Validé le 13 juillet 2026 sur WordPress 7, PHP 8.3, OceanWP et Elementor :

- navigation privée sans session WordPress ou Google sur ordinateur et Android ;
- validation progressive de l'identité et rejet d'une date impossible ;
- parcours sans certificat conforme, référence `QS-2026-000007` ;
- parcours avec certificat conforme, référence `QS-2026-000008` ;
- e-mails, PDF conditionnel et cloisonnement des informations conformes ;
- page publique `https://karate-seremange.fr/questionnaire-mineur/`.
