# Notes de livraison HQ-010

## Objet

HQ-010 professionnalise l'accès public au questionnaire mineur sur le site du club.

## Livré

- page d'entrée responsive intégrée à l'extension WordPress ;
- présentation du parcours en trois étapes ;
- rappel visible de confidentialité ;
- bouton d'accès direct au formulaire ;
- adresse d'assistance du club ;
- maintien du shortcode HQ-009 ;
- documentation d'installation et tests contractuels.

## Hors périmètre

HQ-010 ne modifie ni les questions, ni la décision médicale, ni Apps Script, ni les
PDF, ni les notifications. Aucune nouvelle donnée n'est enregistrée.

## Version

AKS Platform Connector 0.11.0, cumulative depuis RC 0.7.0.
